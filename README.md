# SWYNEX - Exploratory Data Analysis

## Project Overview
This project focuses on Exploratory Data Analysis (EDA) of the Titanic dataset as part of Task 2 of my SWYNEX internship.

The objective is to analyze passenger data using statistical methods and visualizations to discover meaningful patterns and relationships.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Dataset overview and statistical summary.
2. Survival distribution analysis.
3. Age distribution analysis.
4. Gender vs Survival analysis.
5. Passenger Class vs Survival analysis.
6. Age vs Survival analysis.
7. Fare vs Survival analysis.
8. Embarkation Port vs Survival analysis.
9. Correlation analysis.

## Key Findings
- Gender was strongly associated with survival.
- First-class passengers generally had higher survival rates.
- Age provided useful insights into survival patterns.
- Higher ticket fares were associated with better survival outcomes.
- Survival rates varied across embarkation locations.

## Conclusion
The analysis helped identify important factors associated with passenger survival. These findings can support feature selection and future machine learning model development.
